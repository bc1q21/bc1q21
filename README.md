# bc1q21

Smart Contract Giving, powered by bc1q21.com

A Bitcoin-native, non-custodial system for creating time-locked gifts directly on the Bitcoin blockchain.

---

## What is this?

bc1q21 is a simple tool that allows anyone to lock Bitcoin into the future using Bitcoin’s built-in time-lock functionality.

Once a gift is created, the Bitcoin is secured and enforced by the Bitcoin network itself — not by this website, not by any company, and not by any third party.

---

## How to think about bc1q21

Think of bc1q21 like a billboard on the side of the road.

It helps you create a Bitcoin time-locked transaction — but once that transaction is created, everything is enforced by the Bitcoin blockchain.

We do not hold funds.  
We do not control access.  
We do not store user data.  

---

## Core Principles

- Non-custodial (we never hold your Bitcoin)
- Bitcoin Layer-1 only (no altcoins, no sidechains)
- Privacy-first (no personal data stored)
- Open-source and transparent
- User responsibility and sovereignty
